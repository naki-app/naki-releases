# Naki: desktop releases

Installers for Naki on macOS and Windows, and the feed the installed apps update from.

- **Download:** the latest release, or the download page on the Naki website.
- **Files in each release:** `Naki-mac.dmg`, `Naki-windows.exe`, the signed update files (`.app.tar.gz`, `.sig`) and `latest.json`, which the apps check for updates.

Releases are published by the build workflow; nothing is committed here by hand. The source code is not in this repository.
